Privacy Policy

AI Content Lab Uploader · Last updated 12 October 2026

AI Content Lab Uploader is a personal tool run by the owner of the AI Content Lab YouTube channel. It uploads the channel's own videos to YouTube. It is not offered to other people.

What data it uses

When the channel owner signs in with Google, the app receives permission to upload videos and read basic channel information (channel name and the list of the channel's own uploads) using the YouTube Data API. It does not access email, contacts, files or any other Google data.

How the data is stored

The sign-in token is stored only on the owner's own computer. No data is sent to, stored on or shared with any other server or third party, and nothing is sold or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions or the Google security settings page. Deleting the token file on the owner's computer also removes the app's access.
